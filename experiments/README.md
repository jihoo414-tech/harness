# 하네스 실험

목적: 나에게 효과적인 워크플로 + 하네스를 찾는다. 실험으로 확인하고, 채택된 것만 `plugin/`과 `WORKFLOW.md`에 반영한다.

## 무엇을 재나

| 지표 | 방법 |
|---|---|
| **주도권 점수 (1순위)** | 1~5, 실험 README에 손으로 적는다. "코드를 이해하고 통제하고 있었나" |
| 세션 시간 | `measure.py` (첫 메시지~마지막 메시지, 쉰 시간 포함) |
| 개입 횟수 | `measure.py`: 내 메시지 + 도구 거절 + 중단(Esc) |
| 토큰 | `measure.py` (입력은 캐시 읽기 포함) |
| 품질 | 숨겨진 인수 테스트 통과율 (`measure.py --junit`) |
| 소감 | 한 줄, 손으로 |

## 과제: Spring 카타

- Spring Boot 4.1, Java 21, Web MVC, JPA, H2. 슬라이스 테스트(`@WebMvcTest`, `@DataJpaTest`) 기본. Testcontainers는 실제 작업에서만.
- 크기: 기준선 워크플로로 약 45분, slice 3~5개. TicketFlow 느낌의 도메인(좌석 홀드, 예매 기간 정책, 대기열 등).
- 스펙은 HTTP 계약(엔드포인트, JSON, 상태 코드)만 고정한다. 내부 설계는 자유.
- 인수 테스트는 HTTP 블랙박스 테스트. 실험 중에는 보지 않고, 끝난 뒤 복사해 돌린다.
- 카타 풀은 레포 밖 `~/harness-katas/`에 두고, 실험 폴더 설정에서 그 경로 읽기를 deny한다.
- 실험은 `experiments/_template/`(Spring 뼈대)를 복사해서 시작한다. 세팅 시간이 측정에 섞이지 않게.
- 실험 폴더에서 `claude`를 켜면 하네스 루트의 `.claude/settings*.json`은 적용되지 않는다(스킬 파일은 상위에서 보인다). 그래서 플러그인, 스킬 on/off, 카타 읽기 차단은 `_template/.claude/settings.json`에 직접 둔다. **이 파일이 실험의 하네스 설정이다.** 변수를 바꾸는 실험은 복사한 폴더의 이 파일을 고친다.
- 템플릿 테스트 한 번은 약 15초(첫 실행은 의존성 다운로드로 약 45초).

카타로 비교하고, 통과한 것은 실제 작업에서 검증한다.

## 규칙

- 한 실험에서는 하나만 바꾼다. 대상은 하네스 전부(스킬, 훅, CLAUDE.md/규칙, 모델·강도, 위임 수준, 워크플로 순서).
- 고정 조건(모델, ponytail 레벨, 스킬 설정, 하네스 커밋)은 `measure.py`가 `metrics.md`에 기록한다.
- **비교 모드(기본)**: 실험마다 새 카타. 기준선(`01-baseline`)과 비교한다.
- **다듬기 모드**: 한 변형이 2번 연속 보류/폐기면, 같은 카타를 반복하며 방법을 다듬는다. 시간 수치는 학습 효과로 오염되니 주도권 점수와 소감만 본다. 찾은 방법은 비교 모드로 다시 검증한 뒤 채택한다.
- **채택 기준**: 변형당 최소 2회. 주도권 평균이 기준선보다 +1 이상이고, 시간·개입이 확연히 나빠지지 않으면 채택. 애매하면 보류.
- 시간 예산: 하루 1~2시간. 실험 하나는 한 세션에 끝나는 크기.

## 실험 하나 진행하기

1. `experiments/_template/`을 `experiments/NN-이름/`으로 복사하고, 카타 스펙만 넣는다.
2. 그 폴더에서 `claude`를 실행해 카타를 푼다.
3. 숨겨진 인수 테스트를 복사해 돌린다.
4. `python experiments/measure.py experiments/NN-이름 --junit <JUnit XML 폴더>` → `metrics.md` 생성.
5. 아래 형식으로 `README.md`를 쓴다.

```markdown
# NN-이름
- 가설:
- 바꾼 것 (하나):
- 카타:
- 주도권 점수: /5
- 소감:
- 결론: 채택 / 폐기 / 보류
```

## measure.py

`~/.claude/projects/<실험 폴더 경로>/*.jsonl` 세션 기록을 읽는다. 테스트: `cd experiments && python -m unittest test_measure`.
